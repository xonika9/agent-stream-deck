## Platform

web

Этот контекст создаётся для публичной страницы плагина внутри существующего сайта gotacat.dev. Сам продукт — плагин для Elgato Stream Deck на macOS и Windows; это не веб-приложение для управления задачами.

## Stack

Страница встраивается в существующий сайт Gotacat Web: Next.js и Strapi. Используются существующие локализация, навигация и оформление сайта. Репозиторий сайта — gotacat-dev; репозиторий agent-stream-deck остаётся источником правдивых сведений о плагине.

## Users

Основная аудитория лендинга, выбранная пользователем: владельцы Stream Deck, которые уже работают с программными агентами. Страница должна объяснять пользу плагина и вести к установке.

Посетителю не требуется понимать GitHub. Ссылку на страницу должно быть удобно отправить человеку как самостоятельное представление продукта.

## Product Purpose

Agent Deck показывает состояния задач на физических клавишах Stream Deck и предоставляет действия для работы с поддерживаемыми настольными приложениями. Основной сценарий — видеть, какие задачи работают, завершились или требуют внимания.

Назначение лендинга, подтверждённое пользователем: публичное представительство проекта, которое объясняет, что это за продукт, как его установить и как он работает. Дополнительная цель — направлять посетителей в авторский блог. Сейчас публичное представление плагина находится на GitHub.

## Positioning

Шесть динамических клавиш объединяют задачи Codex, OpenCode и T3 Code на macOS. Для Codex доступны выбор конкретной задачи и нативные действия Micro; OpenCode и T3 Code показывают состояния и выводят соответствующее приложение на передний план.

## Operating Context

- Основная платформа разработки — macOS; Windows сохраняет самостоятельную локальную интеграцию Codex.
- На macOS поддерживаются локальные источники, а также документированные подключения к удалённым Linux-источникам через сохранённые SSH-соединения.
- Пользователь устанавливает плагин и необходимый для своей платформы запускатель по инструкциям репозитория.
- Рекомендуемая раскладка рассчитана на Stream Deck MK.2 с 15 клавишами; действия и расположение настраиваются пользователем.

## Capabilities and Constraints

- Состояния клавиш: ожидание, работа, необходимость ввода или подтверждения, непрочитанное завершение, ошибка и незанятая позиция.
- Активная очередь выделяет актуальные задачи; отображение ограничено шестью клавишами задач.
- Управление Micro, навигация, выбор усилия рассуждения и создание новой задачи относятся к Codex.
- Индикаторы использования лимитов и оставшихся кредитов работают только для чтения.
- Продукт не имеет телеметрии или облачного сервиса. Привилегированное локальное подключение Codex остаётся на loopback.
- Используются недокументированные внутренние интерфейсы Codex; совместимость может требовать обновлений и указывается для каждого выпуска.
- Возможности Windows нельзя представлять равными возможностям macOS для всех источников.
- Отдельное приложение iPhone и отдельный Codex relay исключены из текущего продукта.
- Первая версия лендинга должна быть на русском и английском; выбор подтверждён пользователем. Объяснение продукта, демонстрационные подписи и инструкция установки должны быть доступны на обоих языках. Название русскоязычного авторского канала сохраняется; англоязычному посетителю нужно явно сообщать язык канала.
- Страница размещается внутри gotacat.dev по /deck для русского языка и /en/deck для английского, с пунктом Agent Deck в общей шапке. Локализованные адреса проверены по правилам маршрутизации существующего сайта.
- Подробный визуальный макет и окончательная проверка состава первой версии ещё не завершены.
- Инструкция на лендинге должна быть понятна без знания интерфейса и терминов GitHub.
- Пользователь согласовал два назначения действий на странице: установка плагина и знакомство с авторским способом работы с агентами. Польза продукта показывается прежде авторской истории и приглашения в канал. Это относится к лендингу, а не к интерфейсу самого плагина.

## Product Principles

- Объяснять пользу через реальные состояния и действия плагина.
- Явно различать возможности источников и операционных систем.
