# Приёмка U8 в установленной среде

Локальные сборки находятся в `outputs/release-v1.0.1/`; перед установкой проверить `SHA256SUMS.txt` из этого каталога. Установка в реальные приложения пока не выполнялась. Эти сценарии требуют отдельного разрешения владельца и доступа к соответствующей среде.

| Среда | Действие и наблюдаемый результат | Статус |
| --- | --- | --- |
| Mac, Codex | Сохранить профиль и неподтверждённый текст; обновить существующий плагин с UUID `com.xonika9.codex-deck`; переустановить watcher из актуального комплекта. Проверить старую кнопку `host-toggle`: UUID/назначения/значки сохранены, работает локальный Codex, старый удалённый выбор игнорируется. | Не проверено в приложении |
| Mac, watcher | Повреждённый комплект или отсутствие Node.js 24 отвергаются до остановки собственной службы; неудачная остановка не заменяет runtime. Успешное обновление подтверждает новый процесс, его блокировку и свежую отметку запуска; частичный отказ явно сообщает ошибку. Проверить, что собственные удалённые слушатели отсутствуют, а OpenCode не затронут. | Автоматическая изолированная проверка; реальная установка не проверена |
| Mac, OpenCode | Проверить `OpenCode` и `Both`, локальные чаты и сохранённое подключение Fedora. Потеря Fedora оставляет локальные карточки; восстановление не добавляет старые завершения. Подтверждение завершения сохраняется локально при ошибке API; новая ревизия появляется снова. | Не проверено в приложении/на Fedora |
| Windows без Mac | Проверить старый профиль, запуск локального Codex, установку watcher и обновление его автономного комплекта. Занятый старый mutex не допускает замены; сбой импорта обнаруживается заранее; новая отметка принадлежит новому процессу. Неподтверждённый SSH не завершается, частные JSON сохранены. Подтверждённый старый relay остановлен. Повторные PID/ошибки не обходят общую задержку десять минут. | PowerShell 7.6.6 на Mac: изолированные функции проверены; Windows PowerShell 5.1/CIM/COM и исполнение Windows не проверены |
| Физический Stream Deck | Записать модель. Нажать карточку A, изменить очередь до отпускания: открывается A. Нажать пустой слот, дождаться B до отпускания: B не открывается. Проверить удержания, настройки, темы, квоты и старые назначения. Проверку сброса проводить без реального расхода кредитов. | Физическое устройство не проверено |

Метаданные приложений не являются приёмкой: OpenCode `2.0.22`, Stream Deck `7.6.0` (`23012`), CodexBar `0.70.0` (`161`). Исторически изученные OpenCode `2.0.5`/`2.0.10` не подтверждают новую версию. Ограниченный поиск стандартных каталогов не нашёл Codex; это не доказывает его отсутствие.

Не записывать адреса SSH, токены, личные пути, содержимое чатов и пользовательские профили в публичный отчёт. Общая приёмка R1–R14 остаётся незавершённой до наблюдаемого результата перечисленных живых сценариев и физического устройства.
