# U7: проверки качества и границ, первая фаза

Состояние: конфигурация, проверки границ и необходимые правки анализа готовы. Массовое форматирование исходников ожидает отдельного коммита первой фазы. Исходная ревизия: `9efcaf0cc5237de908bdecf5dbdc44b384490a47`; Node.js `24.16.0`, Biome `2.5.15` закреплён точно. Установка выполнена через `npm ci`.

## Что проверяется

`npm run lint` проверяет поддерживаемые исходники TypeScript/JavaScript, тесты, скрипты, TypeScript-средства запуска, корневые JSON и принадлежащий проекту `static/manifest.json`. `npm run check:boundaries` запускает настоящий граф Biome, запреты импортов и структурные правила на `src`. Проверка циклов явно включает типовые импорты: `noImportCycles.ignoreTypes=false`.

Между владельцами разрешены только точные публичные имена `#codex`, `#opencode`, `#agents`, `#stream-deck`, `#usage`. Запрещены внутренние файлы другого владельца, относительные обходы, абсолютные пути, неизвестные имена и подкаталоги публичных имён. Codex и OpenCode независимы и не импортируют Stream Deck или SDK; источник квот также не зависит от SDK. Область `agents` импортирует только собственные файлы; глобальные средства процесса и сети запрещены. Существующие владельцы имеют плоскую структуру: родительские относительные переходы запрещены, кроме точечных обращений к существующим общим средствам `src/runtime`.

Исключения относятся к точным файлам: `codex/bridge.ts` и `codex/source.ts` могут использовать существующие общие пути и идентификатор узла; `opencode/secret.ts` и `stream-deck/controller.ts` — только общие пути. Целые области не исключены.

JavaScript встроенного интерфейса Codex содержится в строках. Для него не заявляется проверка дерева JavaScript средствами Biome и не вводятся исключения целых файлов: проверки исполнения выражений в существующих тестах сохранены. Вычисляемые загрузки уже загруженных модулей приложения остаются частью этих строковых выражений.

## Наблюдаемые ограничения инструмента и обходы

Проба настоящего Biome показала, что `src/**` в ограничении подключаемого структурного правила не запускает его; `**/src/**` запускает. Итоговые отрицательные пробы выполнялись с действующим правилом, а не только с проверкой типов.

Нативное `noRestrictedImports` в Biome `2.5.15` пропускает строковый `require()` как отдельное выражение и как присваивание, а также встроенный тип `import("…").T`. Проверка графа ловит цикл строковых `require()`, но пропускает цикл встроенных типовых выражений. Команды, исходники и фактические результаты отдельных проб без подключаемого правила сохранены в `evidence/u7-boundaries.json`.

Поэтому в областях ESM структурное правило требует обычный `import` или `import type`: отклоняет `require()`, `TsExternalModuleReference` и `TsImportType`. Это обратимый обход конкретно воспроизведённых дырок в проверке направления и типовых циклов. В существующем дереве областей таких узлов нет; реальные загрузки внешнего приложения находятся внутри строк и не изменены. После устранения ограничений Biome этот обход можно убрать, повторив сохранённые пробы. Отдельный архитектурный пакет и старый TypeScript Compiler API не введены.

## Объём и исключения

Генерируемый `package-lock.json`, сборки, зависимости, чужие иконки и ресурсы не форматируются. Исторические материалы `docs/maintenance/evidence` исключены из автоматического переписывания: они фиксируют прежние наблюдения, а не поддерживаемые исходники продукта. Новые доказательства U7 записаны отдельно. HTML/SVG, Markdown, YAML и PowerShell не заявляются полностью проверенными Biome. `tsconfig.json` уже включает исходники, тесты, TypeScript-скрипты и средства запуска, поэтому содержательное изменение его охвата не требовалось.

Рекомендуемый набор правил действует вместе с архитектурными запретами. `noNonNullAssertion` отключён как правило стиля: существующие явные утверждения сохраняются, а строгий TypeScript с `noUncheckedIndexedAccess` продолжает проверяться. В одном файле контроллера сохранён существующий параметр SDK `KeyAction<{}>` через точечное отключение `noBannedTypes`; в существующих сложных фикстурах `controller.test.ts` сохранены два приведения к `any` через точечное отключение `noExplicitAny`. Правила направлений, циклов и вычисляемых загрузок остаются включёнными во всех этих файлах. Намеренное удаление/отклонение управляющих символов сохранено с комментариями подавления на соответствующих регулярных выражениях.

## Доказательства и тесты

Стратегия выбрана до записи: конфигурацию проверяют временные нарушения настоящим инструментом, без новых модульных тестов, копирующих конфигурацию. Все временные нарушения удалены. Сохранённые 34 сценария включают циклы из двух/трёх узлов, типовой цикл, прямой/обходной/абсолютный импорт, путь Windows с двумя видами разделителей, `file:` URL, реэкспорт, типовой импорт, вычисляемый импорт/require и разрешённые публичные/внутренние входы.

Поведение продукта не меняется. Правки исходников ограничены явными типами файловых дескрипторов, типовыми импортами, разделением вызова `reject` и выхода из функции, эквивалентной проверкой сохранённого нажатия через `?.` и комментариями подавления. Добавленных тестов нет. Единственная правка теста — комментарий перед существующей проверкой очистки заголовка; входы, утверждения и ожидаемые результаты не изменены. Новые экспорты ради тестов не добавлены.

До изменения проверки нажатия выполнена характеристика существующими тестами: `micro-bridge`, `controller`, `opencode-collector`, `opencode-secure-files`, `codex-bar-usage`, `launcher` — 87 успешных, один пропуск Windows. Они проверяют сохранённые фазы нажатия, исчезновение кнопки, ошибки обновления, дескрипторы и очистку внешних данных, исполнение встроенных выражений. Для этой эквивалентной правки отдельный красный регрессионный тест не добавлен; прямое покрытие внутренних ошибок CDP не заявляется. После правок весь набор дал 205 успешных и один пропуск Windows.

В первой фазе успешно выполнены `npm run lint -- --formatter-enabled=false`, `npm run check:boundaries`, `npm run check`, `npm test`, `npm run validate`, `npm run audit:release`; аудит проверил три корня артефактов. Обычный `npm run lint` пока выявляет только существующие ошибки форматирования; содержательных ошибок и предупреждений нет, остаётся одно информационное предложение стиля. Массовое форматирование намеренно не применено. Проверки в GitHub не запускались: изменена только конфигурация CI для macOS и Windows с Node.js 24 и `npm ci`.

Проверки запущенных приложений и физического Stream Deck не выполнялись. Сборка, тесты и проверки упаковки не являются такой приёмкой. Механизмы, рассмотренные и не построенные: отдельный сканер импортов и новые тесты конфигурации — необходимое доказательство даёт настоящий Biome; изменение раннера и схем внешних данных — вне U7.
